# CIBA Android

Aplicación móvil de CIBA: plataforma digital cubana de educación parental en los primeros mil días de las infancias.

Lema: «Crecemos acompañándonos».

Este repositorio es independiente del sitio editorial `ciba2.0`. Su objetivo es desarrollar una aplicación Android que facilite la navegación, búsqueda y lectura de contenidos CIBA, con soporte progresivo para uso sin conexión.
